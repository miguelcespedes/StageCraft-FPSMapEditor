# StageCraft FPS Map Editor

[English](./README.md) | [Español](./README.es.md)

StageCraft FPS Map Editor is an educational web project for exploring and inspecting a modular 3D FPS arena in the browser.

The project uses `React`, `TypeScript`, `Vite`, and `Three.js` to load an `.obj` + `.mtl` arena, navigate the scene, and inspect individual map elements visually.

## What This Project Does

- Loads a modular FPS arena from `arena.obj` and `arena.mtl`
- Renders the scene in the browser with Three.js
- Provides smooth camera exploration controls
- Lets users inspect scene elements and identify piece names
- Highlights selected 3D parts visually
- Builds a production-ready `dist/` folder with the application and assets

## Project Goals

This project is educational.

It is intended to help study:

- browser-based 3D rendering
- modular frontend architecture
- React + TypeScript integration with Three.js
- scene inspection workflows for FPS-style map content

## Tech Stack

- React
- TypeScript
- Vite
- Three.js

## Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
